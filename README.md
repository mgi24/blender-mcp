# Blender MCP (Fork)

This repository is a fork of the original [ahujasid/blender-mcp](https://github.com/ahujasid/blender-mcp). 
Please visit and read the original repository for comprehensive documentation, features, and advanced usage instructions. 

This fork focuses on providing a simplified and straightforward installation process.

## Quick Installation Guide

Follow these 3 easy steps to install and set up Blender MCP:

1. **Run the Installer:**
   Execute the `INSTALL_UVX.bat` file in this directory. This will automatically set up the required dependencies.

2. **Install the Blender Add-on:**
   Copy the `addon.py` file and install/enable it inside your Blender application as an add-on.

3. **Configure Antigravity MCP:**
   Open your Antigravity MCP configuration folder and copy the settings provided in the `antigravity.json` file into your MCP configuration.
